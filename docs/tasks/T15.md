## Strict task-specific acceptance criteria

- [ ] **T15-AC01** Route slug loads the product; optional variant query selects a valid exact variant. Invalid variant is visibly explained and requires user selection before add.
- [ ] **T15-AC02** Changing color/storage does not silently substitute an unavailable pair. Disabled combinations carry a textual reason.
- [ ] **T15-AC03** Price, availability, max quantity and gallery all come from the same selected variant; existing gallery index resets to a valid image.
- [ ] **T15-AC04** Out-of-stock changes disable add; pending add prevents duplicate click. A route change cancels obsolete product loading.
- [ ] **T15-AC05** Quantity retains only a valid explicit selection; display validation rather than hidden clamping when variant stock becomes insufficient.
