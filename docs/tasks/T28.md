## Strict task-specific acceptance criteria

- [ ] **T28-AC01** Host through HTTPS or localhost; file:// is not a valid deployment for Angular/MSW even though the design prototype can be opened offline.
- [ ] **T28-AC02** Static SPA fallback works for all deep links under /. API paths never silently fallback to index.html; MSW startup failure blocks business actions.
- [ ] **T28-AC03** index.html and mockServiceWorker.js use no-cache; hashed app assets immutable. Do not register Angular PWA worker or delete unrelated origin workers.
- [ ] **T28-AC04** Baseline design budgets: initial JS <=300 KiB gzip, total first-view transferred assets <=1 MiB excluding optional 3D, per-route lazy JS <=150 KiB gzip, CLS <=0.1; record measured local Lighthouse profile, not field-user metrics.
- [ ] **T28-AC05** No analytics, social, chat, consent SaaS, remote font or production API enters the network log; check optimized build separately from coverage build.
- [ ] **T28-AC06** Any approved 3D lives in deferred chunk and separate asset budget; baseline bundle must not include it.
