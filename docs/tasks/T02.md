## Strict task-specific acceptance criteria

- [ ] **T02-AC01** Build a tiny lazy-route canary with true/false branches and verify that leaving one branch unvisited fails UNIT and independently E2E thresholds of 100 for statements, branches, functions and lines.
- [ ] **T02-AC02** An entirely unimported/unvisited handwritten runtime source must contribute zeros and fail both gates; deleting the report, NaN metrics or an empty manifest must fail.
- [ ] **T02-AC03** Exercise a full browser reload and a lazy-loaded route; original TS paths and coverage counters survive segment merging. Do not rely only on resetOnNavigation:false.
- [ ] **T02-AC04** Run browser MSW with serviceWorkers:allow. Unit setup uses setupServer. Never replace SDK/HttpClient with a spy or provideHttpClientTesting for business data.
- [ ] **T02-AC05** Deliberately issue an unhandled /api/v1 request and an external fetch; both cause test failure. Assert MSW request ownership and no open sockets; route interception alone is insufficient for SW-owned traffic.
- [ ] **T02-AC06** The E2E run reaches only the local static host: MSW's unhandled-request policy is fail-closed and a deliberate external fetch fails the test. Browser CSP is an additional barrier, not the sole proof.
