## Strict task-specific acceptance criteria

- [ ] **T10-AC01** Import semantic tokens from mi-bolt-design; dark header/footer, orange #FF6A00 primary with #171B1F text, 8px cards and 6px controls remain normative.
- [ ] **T10-AC02** Implement Button, PriceBlock, ProductImage, ErrorState, LoadingState, EmptyState, FormFieldMessage, QuantityControl, AccessibleDialog and StatusMessage with applicable state contracts.
- [ ] **T10-AC03** Every purchase control target is >=44x44 CSS px, keyboard-operable and visibly focused. Selection is not conveyed by color alone.
- [ ] **T10-AC04** Dialog opens with intentional focus, traps focus, excludes background, closes on Escape/close and restores the trigger.
- [ ] **T10-AC05** No social proof, account/newsletter dead controls, unverified warranty promise or full screenshot as page background.
