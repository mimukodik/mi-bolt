## Strict task-specific acceptance criteria

- [ ] **T07-AC01** Repeated variant merges; different variant remains separate. Add and absolute update reject quantity outside 1..min(stock,5); never silently clamp.
- [ ] **T07-AC02** Only successful atomic cart mutations increment version once. A quote/payment is invalidated on mutation; totals are whole HUF from catalogue prices.
- [ ] **T07-AC03** Same method/path/session/key and normalized payload replay before version checks; different payload returns IDEMPOTENCY_CONFLICT.
- [ ] **T07-AC04** 409 conflicts preserve visible cart until authoritative refetch; 410 expiry creates an explicit recovery choice, not silent checkout continuation.
- [ ] **T07-AC05** No deletion/update succeeds on another session cart; session scoping is isolation, not production-grade authentication.
