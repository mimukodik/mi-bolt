## Strict task-specific acceptance criteria

- [ ] **T12-AC01** Normalize empty/default/unknown query values with the documented canonical URL codec; round-trip brand arrays and storage arrays without duplicates.
- [ ] **T12-AC02** Search debounces 300 ms; filter/sort changes reset page to 1. Use switchMap or equivalent cancellation for generated Observable reads.
- [ ] **T12-AC03** A deliberately slow old response never overwrites a newer query; no effect loop causes duplicate requests.
- [ ] **T12-AC04** Distinct loading/refreshing/success/empty/error states preserve existing useful content; errors never turn into zero results.
- [ ] **T12-AC05** Browser back/forward and direct links restore search, applied filters, page and sort; mobile draft filters remain local until Apply.
