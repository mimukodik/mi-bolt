## Strict task-specific acceptance criteria

- [ ] **T19-AC01** Use stable Angular 22 Signal Forms from @angular/forms/signals; signals own form data and validity; no duplicate FormGroup/BehaviorSubject source.
- [ ] **T19-AC02** Direct deep link or full reload of incomplete checkout redirects to earliest incomplete step with explanation; cart survives but contact/address are cleared on reload.
- [ ] **T19-AC03** Back navigation preserves in-memory fields; a declined payment/order error does not reset contact, address, method or cart.
- [ ] **T19-AC04** Each page can advance only after its own inputs validate and draft save succeeds. Editing earlier data invalidates quote/intent.
- [ ] **T19-AC05** No guard submits an order or starts payment; all writes require explicit UI actions.
